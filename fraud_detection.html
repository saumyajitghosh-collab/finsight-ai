How It Works

The fraud detection model uses XGBoost trained on 120,000 transactions with a 5.2% fraud rate. Features include transaction amount, time patterns, merchant risk, channel, and international indicators. SMOTE balances the minority fraud class. The model achieves an AUC of 0.90, enabling real-time scoring with millisecond latency.
